# bind

BindOS is a custom, power-efficient C++ operating system built specifically for the Waveshare ESP32-S3 Touch AMOLED 2.06. It features a highly optimized BSP with Display TE support, precise PMIC LDO management, and comprehensive sleep modes for maximum battery life. The architecture is split into a robust SD-card OTA recovery tool (rebind) and the main firmware (bindos). Built with extensibility in mind, upcoming features include native apps and watchfaces loaded dynamically from the SD card via ELF loaders, alongside Bluetooth smartphone notifications, Wi-Fi, and step counting.
